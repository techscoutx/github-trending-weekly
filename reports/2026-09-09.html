#3

microsoft/markitdown

Python
⭐ 182,041 🔱 13,372 📈 +2,047 今日 📜 MIT
核心作用 微软出品的万能文档转 Markdown 工具，专为 LLM 设计，保留文档结构。

支持格式

  • 文档： PDF, Word, PowerPoint, Excel
  • 图片： EXIF 元数据 + OCR 识别
  • 音频： 语音转文字
  • 网页： HTML, YouTube URL
  • 其他： CSV, JSON, XML, ZIP, EPUB
使用示例
from markitdown import MarkItDown
md = MarkItDown()
result = md.convert("report.pdf")
print(result.text)  # PDF 转 Markdown
为什么用 Markdown？ GPT-4o 等 LLM 原生理解 Markdown，Token 效率高，能保留文档结构。
